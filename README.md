# Knowing what good looks like

**Making agents you can trust in production.**

Talk given at Connected Women in AI, meetup #2, *Agentic AI in Enterprise: From AI Pilots to Business Value*.
20 August 2026, hosted by twoday, Copenhagen. 20 minutes, followed by a panel.

**[Open the deck](https://olgasafonova.github.io/cwai-talk-2026/deck.html)**

## The argument

An agent is only as good as what it reads before it acts: the tool descriptions, the skill
files, the configuration. Get those wrong and it picks the wrong tool, pulls more than it
needs, and costs you on every call. It looks like the model's fault. It isn't.

We already lint, test and gate our code. None of it points at the files agents read.

The deck walks one lifecycle loop, Plan through Re-harness, and shows what each stage
catches. The closing claim: to trust your agents you have to trust yourself, and that means
knowing what good looks like. Every check in the pipeline is a judgement someone made,
written down and made cheap to repeat.

## Presenting

Arrow keys, page up and page down, or space to move between slides. Home and End jump to
the ends. Full screen the browser before starting.

Animations use staggered fade-rise on text, SVG line-draw on visuals, and a count-up on
slide 9. All of it is gated on a 60 percent IntersectionObserver threshold and replays each
time a slide re-enters the viewport, so scrolling back re-runs the sequence. Everything is
disabled under `prefers-reduced-motion`. Chrome throttles animation in unfocused tabs, so
present from a focused window.

## The numbers on the slides will drift

They were correct in August 2026. Re-derive before quoting any of them.

Slide 9 counts Miro MCP tools: 38 in the official server against 110 in mine. Slide 18
carries the 87 percent automated-evaluator ceiling.

Count my tools from `AllTools`, the list the server actually registers. Counting
`Name:` lines alone gives 109, not 110: `SearchToolSpec` (the `miro_tool_search`
discovery tool, declared in `tools/search.go`) sits in `AllTools` as a bare
identifier rather than an inline literal, so a plain grep cannot see it.

```bash
# 110 on 20-08-2026
awk '/^var AllTools = \[\]ToolSpec\{/,/^}/' ~/Projects/miro-mcp-server/tools/definitions.go |
  grep -cE 'Name:[[:space:]]*"miro_|^[[:space:]]*[A-Z][A-Za-z]*,[[:space:]]*$'

# the official server states its own count on its docs page
# https://developers.miro.com/docs/miro-mcp-tools
# 13 at the February launch, 31 on 12-08, 38 on 20-08
```
